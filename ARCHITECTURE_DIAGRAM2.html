Loom.

A conversational planning system feeds a tracker-resident build. A deterministic scheduler then weaves short planning waves across isolated implementation, review, merge, probe, and repair lanes until every requirement has evidence.

The board is the memory.

A new session can reconstruct the build from tracker state. Local files keep the mechanism alive, but never decide what the build means.

blocked · sticky human hold

One report names attempts and the single decision or external action needed. Only a human release may clear it.

epic acceptance loop

Three ownership rails

Read, write, and run stay separate.

The architecture is safest where each effect has one narrow entry point. These are the seams that keep retryable scheduling, tracker consistency, and provider neutrality from collapsing into one large shell script.

Read / decide

Deterministic control

tick.sh watches, snapshots, admits, locks, launches, sweeps, and notifies. The jq programs turn one snapshot into ordered actions, residue, and deferrals. Neither invents tracker state.

snapshot.jq plan.jq graph.jq mend.jq

Write / commit

Mutation gateways

lane.sh owns every in-lane tracker or forge mutation. bootstrap.sh is the only other setup writer. Tracker and forge drivers hide provider mechanics behind canonical verbs.

trackers/*.sh forges/*.sh mutate.sh

Run / isolate

Provider + host boundary

agent.sh sends one frozen brief to a Claude or Codex adapter. Worktrees isolate code; host-owned gates, browser resources, reconciliation, and probes remain outside the provider sandbox.

Constitution

Four rules shape every arrow.

These are architecture constraints, not stylistic preferences. The diagram’s central tracker, thin mutation gateway, narrow routing layer, and named consumers all follow from them.

01

No shadow state.

Tracker state alone reconstructs every build decision. Run directories contain replaceable plumbing only.

02

Route, don’t teach.

Loom orders phases and gates. Sibling skills own planning, interface design, implementation, and review technique.

03

Rules need scars.

A new behavioral rule must cite a real failure. Deterministic machinery carries the rule when it can.

04

Artifacts need consumers.

Requirements feed tickets, criteria feed probes, briefs feed lanes, and events feed humans. Or the artifact does not exist.

Outside the product build

qa reports Loom defects · fix proves one defect repair failing-first · prop implements one approved proposal · optimize compacts the always-loaded skill contract · retro turns completed-build time and cost into proposals. These maintenance verbs never run inside a wave.
