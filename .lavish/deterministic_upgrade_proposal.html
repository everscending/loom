Every two and a half minutes, a model session wakes up to decide what the build does next — and every input to that decision already exists, computed deterministically, in the snapshot it begins by reading. P81 compiles that decision table into a script, and lets a model see only the residue a script honestly cannot write.

the line the design already draws

What still rents a model — and should

Models judge, scripts plumb. Everything below adds information the tracker does not contain. That is the work worth paying for, and P81 removes none of it.

The gate verdict

Code review against the PRD is judgment, not lookup. The mechanical half already runs in shell first — --pregate exits 7 in seconds without spending a turn.

The implementation

The code does not exist until a model writes it. This is the build.

The epic probe

Exercising the product the way a user would is exploration, not table-reading.

Merge-conflict surgery

A real conflict has no decision table. Resolve the trivial, report the rest.

The blocked report

Names the single decision a human must make. Prose a script cannot write — so it becomes residue, not a template.

The completion report

The narrative a human reads at the end. Written once per build, by the residue session.

why this is safe

The guardrails that keep a planner honest

The plan derives, it never writes

tick.sh is read-only against the tracker today, and a test enforces it by scanning every captured argv against a mutating denylist. plan extends the same scan to the new path — shown failing once the guard is removed.

The plan is disposable

Like the snapshot, it is never written anywhere a later run reads back as state. A plan file that outlived its wave would be exactly the shadow state constitution rule 1 forbids.

Residue sees residue alone

The conditional session gets the leftover items — a blocked report to write, a log tail to classify — never the whole board. Small context, few turns.

SKILL.md shrinks

Steps 2–6 stop being prose a wave interprets and become “run the plan, then handle the residue.” A line reduction in the file every session loads.

the residue is the escape valve

A few wave decisions have ragged edges — reading a dead gate’s log tail to tell an API stall from a crash, writing the blocked report a human will act on. P81 does not pretend those are deterministic. Routing them to a small session that sees only the residue is what makes “the plan is a total function” achievable instead of dogma.

the boundary of P81

Deliberately out of scope — the next candidates

P81 stays narrow so its before-and-after is measurable. These two determinizations wait for the retro numbers after it lands.

The happy-path merge lane

A merge lane is a full model session whose no-conflict path is three script calls: reconcile, re-run gates, merge. A script that escalates to a model only on a real conflict would remove most merge-lane sessions — one per merged ticket.

Templated blocked reports

When a mechanical cap fires — too many crashes, rejections, or merge attempts — the report’s content is enumerable: the attempts, the counts, the links. A template covers it; prose is only needed for what the human must decide.

measure first

What is not yet measured is how much of the 2m28s survives the change — some waves will still have residue to write. Measuring that split is the first job of the implementation, not an assumption to build on. Then retro judges the next candidates with real numbers.

Evidence: seat-reservations build-1 (2026-08-03 — 36 waves, 1h29m, 57.5% of a 2h35m span, 2m28s average) and boostlingo build-1 (2026-08-01 — waves $683 of $3,404 spend; 407 sessions, 28 turns, 118k context per turn). Both are retro output over real builds, not predictions. P81 supersedes the scheduling half of P18; the cheaper-model config half stays worth doing first — one line, costs nothing to try.
